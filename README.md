# Student Mentorship & Project Showcase Portal

## Project Overview
A web application designed to connect students with mentors and provide a platform for showcasing academic projects.

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

## Features
- Home dashboard
- Student registration
- Mentor registration
- Find mentors based on skills
- Send mentorship requests
- Showcase student projects
- Database integration using SQLite

## System Architecture
- **Frontend:** Streamlit
- **Application Logic:** Python
- **Database:** SQLite

## Team Project
Developed as a five-member college project. Team responsibilities should reflect each member's actual contributions.

## How to Run Locally

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required packages:

   `pip install -r requirements.txt`

5. Run the application:

   `streamlit run app.py`
